ZeroProblems

Веб-платформа, которая превращает обезличенную выгрузку обращений граждан в Excel в управленческую аналитику: классифицирует тяжесть каждого обращения дообученной RuBERT и показывает на карте, какие муниципалитеты Омской области в наиболее тяжёлом состоянии — с Health Score, drilldown по районам и LLM-справками.

официальные итоги

// задача

Регион получает поток обращений граждан (жалобы, инциденты, аварии) — десятки тысяч строк в Excel-выгрузках. Вручную понять, где ситуация критическая, по каким темам и какие муниципалитеты требуют внимания в первую очередь, — невозможно. Нужен инструмент, который автоматически оценивает тяжесть каждого обращения и сводит это в понятную для управленцев картину по территориям.

// решение

End-to-end платформа: загрузка Excel → автоопределение формата → классификация тяжести дообученной RuBERT (ONNX Runtime, GPU/CPU) → агрегация в Health Score по муниципалитетам → интерактивная карта, дашборд и drilldown по районам. Поверх — LLM-справки и PDF-отчёты (локальная модель через Ollama, без внешних API), прогноз динамики, ролевой доступ (админ / оператор / аналитик), живая лента и форма подачи обращений. Всё разворачивается одной командой через Docker Compose.

// что сделали

  • 01
    Загрузка и парсинг Excel
    Автоопределение нескольких раскладок колонок, чтение через calamine/openpyxl, очистка и нормализация текста.
  • 02
    ONNX-классификация тяжести
    Дообученная RuBERT, 5 классов тяжести (0–4), батч-инференс на ONNX Runtime с CUDA и fallback на CPU.
  • 03
    Health Score по муниципалитетам
    Взвешивание классов (0→0 … 4→100) и лог-нормировка на объём обращений → единый скор 5–100 на каждый МО.
  • 04
    Карта, дашборд и drilldown
    Leaflet + GeoJSON границ Омской области, рейтинг районов, Top-10 тем, развёртка по конкретному муниципалитету.
  • 05
    LLM-справки и PDF-отчёты
    Локальная модель через Ollama генерирует управленческие справки по районам; отчёты выгружаются в PDF.
  • 06
    Прогноз, роли и приём обращений
    Прогноз динамики обращений, ролевой доступ (админ/оператор/аналитик), живая лента и публичная форма подачи.

// интерфейс

// пайплайн

      Excel  — обращения граждан
              │
       Парсинг  — автоформат, очистка
              │
       RuBERT / ONNX  — тяжесть 0–4
              │
       Health Score  — агрегация по МО
              │
   Карта · дашборд · drilldown
              │
       LLM-справки  — Ollama + PDF
  • Health Score с лог-нормировкой — крупные МО не выигрывают рейтинг просто за счёт объёма обращений.
  • Полностью on-prem: классификатор и LLM работают локально (ONNX + Ollama), данные граждан не уходят во внешние сервисы.
